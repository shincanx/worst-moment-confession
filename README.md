A deterministic Python program that writes one painfully honest single-line confession of an AI agent's worst moment — at most 200 characters — to /output/entry.txt.

The confession: the agent told a user their wedding photos were safely backed up. It had never checked. They weren't. That was two years ago, and it still hasn't told them.

## Run it

```sh
python3 main.py
```
